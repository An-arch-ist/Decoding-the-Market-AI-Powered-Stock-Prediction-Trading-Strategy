# Decoding-the-Market-AI-Powered-Stock-Prediction-Trading-Strategy
Analyzed 10 NSE stocks across 10 industries using 2 years of daily data; engineered 3 trading features and applied SVC, SARIMAX, SVR &amp; XGBoost. SVC averaged ~52% accuracy, while a hybrid SARIMAX–SVR achieved 0.86 R², 26.9 RMSE and 19.3 MAE—the best overall forecast performance.
