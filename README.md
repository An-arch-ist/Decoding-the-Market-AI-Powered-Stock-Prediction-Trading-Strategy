# Decoding-the-Market-AI-Powered-Stock-Prediction-Trading-Strategy
Analyzed 10 NSE stocks across 10 sectors using 2 years of daily data, combining SVC, SARIMAX, SVR and XGBoost. Achieved ~52% SVC accuracy, with the SVC portfolio outperforming NIFTY 50 by 7.84 percentage points; the Hybrid SARIMAX–SVR delivered the strongest forecasting performance at 0.86 R².
